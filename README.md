# Project_Genkai
Boundary experiments — tools, scripts, and small projects built at the edge of Finance, Tech, and AI.

A monorepo where each subfolder is an independent project. The active one today is
**[`lore-engine/`](lore-engine/)** — a schema-driven pipeline that turns unstructured
long-form text into structured, queryable JSON knowledge bases (prototype corpus:
Golden Sun 1). See its [README](lore-engine/README.md).
