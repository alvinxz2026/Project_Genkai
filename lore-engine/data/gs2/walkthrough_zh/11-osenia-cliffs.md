# Osenia Cliffs

当你到达 Osenia Cliffs 时，你会发现人们在呆呆地看着一艘在岸边翻覆解体的海盗船。

### Pirate's Sword

要拿到残骸中的一个道具，沿着小路向北，顺着绳子爬下船。跳到北边的平台（带有旗帜的帆），然后跳到东边的平台。对绳子使用 "Lash" 并爬上去。爬下你下面的藤蔓，到达一个装有 **Pirate's Sword** 的孤零零的宝箱。这是一次出色的武器升级，特别是对 Jenna 来说[^1]。

拿到剑后，爬回藤蔓返回入口。跳到你右边的大岩石上，然后跳到更右边的壁架上。爬下藤蔓，沿着小路向东走，跳过石尖正式进入 Osenia Continent。
