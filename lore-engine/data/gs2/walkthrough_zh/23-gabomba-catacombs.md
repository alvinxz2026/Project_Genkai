# Gabomba Catacombs

**隐藏道具：** 1
- Mint - 在第二个房间的草丛上使用 Cyclone

**宝箱 / 事件道具：** 2
- Game Ticket - 由躲在草丛下的 Mad Plant 掉落
- Tomegathericon - 结束时由 Great Gabomba 赠予

**Djinn：**
- Venus - Mud

**怪物：**
- Mad Plant, Doomsayer, Bone Fighter, Death Head, Spirit, Salamander, Red Demon

一旦你获得 Cyclone Chip，你就可以探索 Gabomba Statue 下方的 Gabomba Catacombs 了 [^1]。通过 Gabomba Statue 的舌头进入并回到你获得 Black Orb 的房间，然后爬下梯子到达地下墓穴。

这个洞穴里有很多杂草，可以被 Cyclone 吹走。爬下梯子，尽可能地靠近梯子左边的大片草地（有一块岩石挡路，所以你必须从右边绕过去并紧贴墙壁）[^2]。在这里使用 "Cyclone"，你会被卷下一个隐藏的坑洞到达下一层，刚好落在一个 Venus Djinni 旁边。保存游戏并与 Djinni 战斗以获得 **Mud** [^3]。从滑道滑下并爬梯子和楼梯回到楼上。

这次，前往房间的左上角到达另一片草地。在这里使用 "Cyclone" 再次被带下去。向左穿过走廊进入下一个房间。向右走，在草地上使用 "Cyclone" 找到一个 **Mint** [^4]。爬下梯子并对更下方的十字形草地使用 "Cyclone" 揭露一个水坑。使用 "Frost" 冻结它，然后爬回去跳过去。在植物圈的中间使用 "Reveal" 以揭露下一个楼梯。

你将出现在一个有湍急河流的房间。你可以通过按住 B 按钮逆流奔跑。向左走进河里，径直穿过去。到了对岸后，向西前往被岩石隔开的一小片草地。在最南端的草地上使用 "Cyclone" 以揭露另一个水坑 [^5]。回到渡河点并在水流中逆流（向北）而上，必要时在岩石后穿梭。当你到达顶部时，向左走到西岸。往下走并对你刚刚揭露的水坑使用 "Frost"。

回到你入河的地方，向右走，爬上西侧的梯子。跳过你刚刚创造的冰柱，上楼梯到下一个屏幕。

在最终区域，爬下梯子并向北走。如果你在大片草地上使用 "Cyclone"，会出现一个 **Mad Plant**。击败它以获得 **Game Ticket** [^6]。继续向北走并爬上梯子找到另一座 Gabomba 雕像。雕像告诉你，因为是你先到达这个地方，它会把魔法给你而不是 Akafubu，但你必须答应不要向他提起这件事。收下它提供的黑色书本，那就是 **Tomegathericon**。这是你的第三个转职道具，能将角色的职业转变为 Dark Mage！

使用 "Retreat" 离开 Gabomba Statue。
