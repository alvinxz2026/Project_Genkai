# West Indra Islet

从 N Osenia Islet 向左航行直到你撞上大陆，然后沿着北部海岸航行。当你撞上另一块大陆时，向南航行到达一个小岛。在这个小岛 West Indra Islet 将你的船靠岸，然后进入小村庄。这个村庄原来只不过是许多木板把浅水区里的一艘小船和一间小屋连接在一起。

可以通过向左走，然后在尽头向上走来找到 Lucky Medal。继续向上，检查船旁边木板上的桶。现在往回走一点，走右边的小路。当你到达小屋时，继续向右走，跳过柱子到另一边。跑下楼梯，绕过浅水区到达狗那里。对它 Mind Read 并给它你的 Milk。它会用它抓到的一只 Li'l Turtle 作为奖励给你。

这就是这个小岛所能提供的一切，所以我们再次起航。
