# Atteka Inlet

当你到达 Atteka Inlet 时，你会在你的船上。向南走，爬下壁架，顺着小路向左走到达海滩。

向北走，找到几个守卫着巨大棕色翅膀的人。他们提到翅膀是预言的一部分，并且当 Mt. Jupiter 燃烧时会被安装在一艘船上。继续向左走离开这个区域。

在下一个屏幕上，爬上左边的山丘。爬上两片树林之间的梯子。向右走过城镇标志，直到你到达下一个屏幕。爬下藤蔓并打开装有 **Vial** 的宝箱。原路返回，爬下梯子，通过左边或北边的门离开港口。

**关于世界地图 Djinn 的注意事项：**
- 在到达 Atteka Inlet 之前，你可以找到 Venus Djinni **Petra**。在 Hesperia 北部的河流航行，直到你到达一个在山脉尽头的小分支。在树林周围跑动遭遇 Petra。
- 沿着 Atteka 大陆的左侧，在环形河流之间树木繁茂的区域跑动，可以遭遇 Mars Djinni **Core**。

# SW Atteka Islet

*（在游戏后期，Jupiter Lighthouse 被点燃且你获得了 Hover Psynergy 后，你可以探索 SW Atteka Islet 并为你的船获取翅膀）。*

一旦你有了 Hover Psynergy，回到 Atteka Inlet。在你进入的区域的西南部，对巨石使用 Lift，然后对杂草使用 Cyclone 发现 Mars Djinni **Geode**。你不用和它战斗。

去你的船所在的区域，发现翅膀已经装上了！Hamma 会来迎接你。有了翅膀，你的船现在可以使用 Hover 飞过暗礁和小岩石。如果你在第一部游戏中救了 Hammet，来自 Vault 的信使会到达并给你 **Orihalcon**。

现在，航行到位于 Atteka 西南部的 SW Atteka Islet。这个微小的定居点摇摇欲坠地悬在 Gaia Falls 上方。
- **Dragon Skin**: 爬下帐篷下方的藤蔓，将柱子推入水中。爬回来，将箱子从岛的左侧部分推入小瀑布中。它会掉下去但被柱子挡住。你现在可以跳过去获得 Dragon Skin。
- **Jupiter Djinni**: 举起一块巨石并跳过去到达一个 Jupiter Djinni 处（如果你没有把它们从上一部游戏中全部继承过来的话）。
