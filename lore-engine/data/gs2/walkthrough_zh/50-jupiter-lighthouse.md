# Jupiter Lighthouse (入口和主塔)

要去灯塔，航行到 Atteka Inlet 然后在这个大陆上一直向北走。
在灯塔外面，对右下角的灌木丛使用 **Cyclone** Psynergy 获得一个 **Mint**。你还会发现一个在死胡同里的 Cyclone 传送阵——使用它进入地下。对杂草使用 Cyclone 发现一株 **Mad Plant**；如果你想的话就打败它。继续沿着最右边的路走，在紫色能量格上使用 **Hover** Psynergy 向右飘。在那里使用 Cyclone 传送阵回到灯塔里，然后把柱子推到按钮上打开大门。

上去进入中央大房间。顺着左边的路走，到一个推圆木谜题处。推着圆木走，拿到装有 **Erinyes Tunic** 的宝箱。
穿过门口，使用 Cyclone 垫子上到上面一层。再次进入建筑，沿着外面的左下路线走到另一个入口，上楼梯，并使用 **Reveal** 到达一个跳跃谜题房间。在这里从宝箱里拿回 **Meditation Rod**。走到外面，把灰色方块推向右边，并站在按钮上让方块掉下去以开辟一条捷径。

从左上角的楼梯上去，沿着路前往灯塔的顶层平台（aerie）。放 Jupiter Star 的缺口被盖住了，所以走进左边的入口。滑下去，靠近房间中央。一个声音会提示你“展示 Anemos 的力量”。爬上梯子并在平台上使用 **Hover**。这会激活灯塔里所有的悬浮平台！

在最右边通道的紫色格子上使用 Hover 拿到 **Red Key**。往下走回到有 Reveal 平台的房间拿一颗 **Psy Crystal**。回到你之前跳过的 Cyclone 垫子，上一层，在红色的门上使用 Red Key，然后走到外面。躲避石脸吹出的旋风并继续前进。

# 左塔

进入左塔。左边的宝箱是一个包含 **Mimic** 的陷阱（打败掉落一颗 **Psy Crystal**）。走右边的通道上去。你会看到一把蓝钥匙，但你现在从这里够不到它。上楼梯进入一个满是裂开地板砖的房间。
- 走右边的路线会让你落在一个装有 **306 Coins** 的宝箱附近。
- 走左边的路线并把柱子推下缝隙能让你拿到一瓶 **Mist Potion**。

前往塔顶。在有许多裂开地砖的房间里，使用 Hover 到达最左边的柱子，把它推到按钮上，然后通过半空中的地砖 Hover 到右上角并上楼梯。
在外面，你会看到一尊巨大的石制弓箭手雕像。把能量方块推入缝隙中，弓箭手就会射出一支箭给左边的天使充能，从而升起顶层平台左半边的盖子。
回到里面，从唯一那块裂开的地砖掉下去，收集 **Blue Key**。回到主塔。

# 主塔和右塔

回到主塔，使用 Cyclone 传送阵下去。移动你遇到的各种灰色柱子，在塔的左右两半之间建立捷径。一旦到了右边，从宝箱里拿出一瓶 **Potion**，并在蓝色的门上使用 **Blue Key**。在外面使用 Hover 到达右塔。

在右塔里面，你会发现一个大房间，左边有一只 Jupiter Djinni。把能量路径格推入缝隙中。对柱子使用 Pound 露出方块，然后排列它们以够到 Jupiter Djinni **Whorl**。击败 Whorl 让他加入你的队伍！
你可以重新排列方块够到一个装有 **Water of Life** 的宝箱。

继续爬塔。在有许多悬浮格的房间里，小心躲避雕像吹出的旋风。左边的通道包含 **Phaeton's Blade**（把它装备给 Felix）。顺着悬浮格后面右侧的岔路走，在半空中跑动以躲避雕像。在外面，重复弓箭手雕像谜题以移除顶层平台的右半边盖子。

# 顶层平台 (The Aerie)

原路返回到灯塔顶层平台。当你靠近时，你会目睹 Isaac 的队伍落入 Karst 和 Agatio 设下的陷阱。在一段过场动画中 Alex 完全治愈了你的队伍，之后 Isaac 和 Ivan 把 **Mars Star** 交给 Felix，要求他点燃烽火，而他们则照顾伤员。

Felix 和 Piers 前往顶层平台。把 **Jupiter Star** 扔进井里点燃烽火。然后 Karst 和 Agatio 会与你反目，偷走 Mars Star 并引发一场 Boss 战。

**Boss: Agatio & Karst**
你开始战斗时只有 Felix 和 Piers。在第 3 回合，Jenna 加入战斗，而在第 5 回合，Sheba 加入。Agatio 能造成巨大的物理和火属性伤害，而 Karst 可以使用 Djinnfest 使你的 Djinn 进入恢复模式。首先将你最强的攻击集中在 Agatio 身上。让 Jenna 或 Mia（如果你使用 Djinn 切换了职业）不断施放 Wish 或 Aura。击败他们后，他们就会逃跑。收集他们留下的 **Dark Matter**，乘电梯下去，离开 Jupiter Lighthouse 去 Contigo 和其他人重新汇合。
