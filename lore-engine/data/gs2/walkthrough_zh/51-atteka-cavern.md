# Atteka Cavern

你只有在你的 Lemurian Ship 安装了翅膀、允许它在暗礁上悬浮之后，才能到达 Atteka Cavern。航行到 Atteka 大陆的南部边缘并找到洞穴入口。

在洞穴里面，向右走直到你到达一个有一些水的死胡同。面对水，使用 **Parch** Psynergy 将它完全蒸发。

水消失后，走到房间左侧爬上梯子。顺着小路走并爬下第二个梯子。向南走，爬上放着石板的壁架。检查石板以获得 summon **Coatlicue**。这个 summon 需要 3 个 Mercury 和 3 个 Jupiter Djinn 处于待命状态，它的力量能恢复你所有角色的 HP！

拿到石板后，你在这里就完事了，可以回到你的船上。

# Angara Cavern

Angara Cavern 位于矮人采矿营地 Loho 的正北方（如果你从北岸来就是向南走）。顺着磨损的小路走过桥，到达洞穴入口。

在里面，向北走，下楼梯。一直往下走，直到你到达一扇门，然后穿过它。你会发现自己在一个需要使用 **Carry** Psynergy 解开谜题的房间里。

1. 首先，向北走，把在地上的方块向右推一格。
2. 爬上梯子，走向上面那个方块，把它推向壁架。
3. 使用 **Carry** Psynergy 把它放下去。
4. 回到一楼，使用 **Move** 把那个方块向左推，让它和另一个方块并排。
5. 对下面那个方块使用 **Carry** 把它抬起来并放在另一个方块上面。

一旦方块堆叠起来，跳过它们到达放着石板的壁架。检查它以获得 **Haures** summon！Haures 需要 3 个 Venus 和 2 个 Mars Djinn 处于待命状态。完成之后，离开洞穴回到你的船上。
