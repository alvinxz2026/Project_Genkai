# Kalt Island

一直向北航行，直到你到达一个被冰雪覆盖的小岛。在这个岛南部的海滩上登陆，然后向北走进入只有一个房子的村庄。立刻你就会看到一个 Djinni。

如果你向右走，你会看到一条结冰的河流，那里有一个结冰的区域，你必须从一块岩石滑到另一块岩石才能移动。向北走，穿过篱笆上的缺口向西走。这是在冰上导航的指示：

1. 向左走。
2. 向下走。
3. 向右走。
4. 向上走。
5. 向左走。
6. 向上走。
7. 向右走。
8. 向上走。
9. 向左走。
10. 向上走。
11. 向右走。
12. 向上走。
13. 向左走。
14. 向下走。
15. 向左走上雪地。

爬上梯子，然后对绳圈使用 Lash。爬上绳子向右走。爬下梯子和 Djinni 说话。Mercury Djinni **Gel** 会直接加入你不用战斗。

回到结冰的河流。如果你想要一个 Apple，你可以去拿湿滑冰面左边树上的那个。滑行：右，下，左，下，左，并使用 Catch 抓住 Apple。然后，回到你的船上并向南离开镇子。
